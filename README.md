#3D Tank - Node.js Multiplayer Gameレトロなワイヤーフレーム調の3D戦車ゲームを、Node.jsとSocket.ioを用いてリアルタイムマルチプレイヤーゲームへと進化させたプロジェクトです。

サーバー側でゲームロジックとオブジェクトの座標を完全に管理・同期しています。
🚀 特徴リアルタイム・マルチプレイ: 複数のブラウザやタブからアクセスすることで、同じフィールド内で他プレイヤーとリアルタイムに同期・対戦が可能です。
サーバーサイド管理: 戦車の移動、弾の軌道、敵NPCのAI、および当たり判定（衝突判定）はすべてNode.jsサーバー側で処理され、各クライアントへ等しく配信されます。
ハイブリッド描画: * フロントエンドのHTML5 Canvas（2D Context）を用いて、疑似的な3Dワイヤーフレーム空間を描画。戦況を俯瞰できる2Dレーダーマップも同時描画。
モダンJavaScript: レシーな構文から、ES6+（class構文、let/const、アロー関数）ベースへと完全にリファクタリングしています。
🛠️ 技術スタックサーバーサイド: Node.js, Expressリアルタイム通信: Socket.ioフロントエンド: HTML5 Canvas, Vanilla JavaScript (ES6+)
📦 セットアップと実行方法1. 必要条件PCに Node.js (v14以上推奨) がインストールされていることを確認してください。
2. インストールプロジェクトのルートディレクトリで以下のコマンドを実行し、依存パッケージをインストールします。Bash# プロジェクトの初期化（未実施の場合）
npm init -y

# 必要なライブラリのインストール
npm install express socket.io
3. サーバーの起動以下のコマンドでゲームサーバーを立ち上げます。Bashnode server.js
起動に成功すると、ターミナルに Server running on http://localhost:3000 と表示されます。
4. ゲームのプレイブラウザを開き、以下のURLにアクセスします。http://localhost:3000
💡 マルチプレイのテスト方法:ブラウザのシークレットウィンドウを開くか、別のタブ・異なるブラウザ（ChromeとEdgeなど）で同時に同じURLを開いてみてください。
お互いの戦車が同期して画面やレーダーに出現します。🎮 操作方法キー動作矢印キー（↑ / ↓）前進 / 後退矢印キー（← / →）旋回（カメラおよび砲塔の向きを変更）スペースキー弾を射撃
🗺️ 画面の見方メイン画面 (左側 600x600): 自機視点（FPS）の3Dワイヤーフレーム空間です。
